# Hamro Saathi (हाम्रो साथी)

**A Gentle Learning Companion**

Hamro Saathi is an autism-friendly e-learning platform designed for children with Autism Spectrum Disorder (Support Level 1–2). The platform uses interest-based learning to create a calm, engaging, and accessible learning experience through simple visual activities and caregiver support.

This project is being developed as a hackathon MVP.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- Vercel

## Getting Started

Clone the repository:

```bash
git clone https://github.com/HimanchalK/GMC_DeployOrDie.git
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_publishable_key
```

Start the development server:

```bash
npm run dev
```
